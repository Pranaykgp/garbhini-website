# Garbhini — website redesign

A redesigned homepage for Garbhini, a maternity care platform: doctors, lab tests and scans, trimester guidance, nutrition, community and products.

## View it

Open `index.html` in a browser. Keep the `img/` folder next to it.

## Files

- `index.html` — the full page, ready to host (for example on GitHub Pages).
- `garbhini.html` — the page source without the outer HTML wrapper.
- `build-local.sh` — rebuilds `index.html` from `garbhini.html` after edits.
- `img/` — logo and photos.
